## 👩‍💻 About me

<img align="right" src="https://media.giphy.com/media/cUAGuLiEcTBwRfkAQq/giphy.gif" width="260"/>

I'm a **Senior Software Engineer from Karachi, Pakistan** with around **4 years** of hands-on experience building cross-platform apps.

- 📱 Shipped **10+ apps** on Google Play and the App Store with a **4.6★+** average rating
- 🌍 Built for clients in **Canada, the US, the UK, the UAE, Australia, Kenya and India**
- 🧩 Flutter & Dart first, with native **Swift** and **Kotlin** through platform channels
- 🌐 Web front ends in **React, Next.js and Angular**, back-ends in **Node.js** and **PHP**
- 🤖 Bringing **AI / LLM features** (chat assistants, smart content tools) into every product
- 🧭 Team lead & project manager: sprints in Jira, code reviews, **mentored 4 junior developers**
- 🚀 Set up **CI/CD with GitHub Actions + Firebase**; cut a logistics app's load time by **40%**
- 💼 **Open to freelance:** mobile apps, web apps, AI projects and project management
